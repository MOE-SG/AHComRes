Airhang QC

COMRES Airhang Spec Checker

One favorite, click once on any open Airhang report. It reads every parameter table on the page and marks each value pass, fail, or no spec yet against limits you maintain in one file — no reinstall needed when the spec changes.

Step 1 — install
Drag the button to your favorites bar
If your favorites bar is hidden in Edge, press Ctrl+Shift+B first.
⌁ COMRES Airhang Check drag — don't click — onto the bar above your tabs
— or, if drag-install doesn't work on your setup —
copied — paste into a new favorite's URL field
Step 2 — run it
Open the report, click the favorite
Open the .htm Airhang report in Edge, click ⌁ COMRES Airhang Check in the favorites bar. A panel drops in top-right with a pass/fail count and a list of failures you can click to jump to. Every checked cell in the report is colored inline:
■ pass ■ fail ■ no spec yet ■ na (skipped)
Step 3 — tune the spec
Edit one file, push, done — no reinstall
The button only loads comres-airhang-spec-checker.js fresh from this repo every time it's clicked. Edit the SPEC object at the top of that file, commit, push — the favorite picks up the change on the next click. The in-page Edit Spec panel will also hand you a ready-to-paste JSON skeleton of every parameter name actually found in whatever report is open, so you're not guessing labels.
